臺灣棒球資料標準 v0.4 草案
本文件為國家運動科學中心（TISS）委託制定之棒球資料標準草案，採 Standards-as-Code 架構，以 YAML 為唯一真相來源，本 HTML 文件及 OpenAPI 規格均由 CI/CD 自動生成。本標準所定義之欄位為完整概念範圍，實際資料是否收錄，依各資料來源單位可提供之項目與後續介接進度逐步納入，詳見下方「欄位收錄原則」。
§1 · 適用範圍（Scope）
維度 說明
欄位收錄原則 本標準列出之欄位為完整概念範圍，供未來擴充依循；實際是否收錄特定欄位之數據，依該資料是否可自資料來源單位取得而定，並非本案承諾一次到位蒐集所有欄位
參與者層級 職業（PRO）、業餘（AMT）、U23、U18、U15、U12、一般民眾（PUBLIC，含教學／培訓機構學員）
資料情境 正式比賽（Game）、訓練課次（Session，含教學／培訓機構訓練紀錄）、選秀體測（Combine）
地理範圍 中華民國（臺灣）主辦，或我國球員／民眾參與之賽事或活動
感測層欄位 比照國際職業棒球聯盟公開量測項目定義之欄位（如出手速度、轉速等），依場館實際感測設備配置及資料可得性逐步納入；欄位均為選填，無設備時以 null 填入
單位政策 量測欄位一律採公制，並依 ISO/IEC 11179 於欄位名稱後綴標註單位（如 release_speed_kmh、lead_distance_m）。例外情形以下列兩類為限，且均於該欄位附註載明理由：
（一）名稱本身為既定測試協定或器材規格慣例者，如 sprint_60yd_sec（球探標準測試名稱）、string_tension_lbs（羽球穿線磅數之國際通行慣例）——此類名稱中之英制字樣為測試協定名稱之一部分，非量測單位。
v0.5.0 撤銷之例外：原 plate_x／plate_z／sz_top／sz_bot 保留英尺以對齊 Statcast 好球帶分區定義一項，因野球革命建議書採全公制座標系（本壘板尖端為原點、單位公尺），為兩方架構一致並貫徹「量測欄位一律公制」原則，本版改採公制並撤銷該例外，欄位更名為 plate_loc_x_m／plate_loc_z_m／sz_top_m／sz_bot_m。
來源設備之原生單位與換算係數一律記載於該欄位附註，供 ETL 對照使用。

單位縮寫對照（本標準所用之後綴縮寫，一律採公制語意）：kmh＝公里／小時（km/h，非節）、mps＝公尺／秒（m/s，非英里／秒 miles per second）、cm＝公分、m＝公尺、rpm＝每分鐘轉數（revolutions per minute）、deg＝角度（°）、sec＝秒、min＝分鐘、pct＝百分比（%）、c＝攝氏度（℃）。例外後綴（政策例外，非公制）：ft＝英尺（僅好球帶座標系統）、lbs＝磅（僅羽球穿線磅數）、yd＝碼（僅 sprint_60yd_sec 測試名稱）
座標系 三維空間座標一律以本壘板尖端為原點，X 軸向右為正、Y 軸指向投手丘為正、Z 軸向上為正，單位公尺。
採本壘板尖端而非好球帶中心之理由：好球帶之上下緣隨打者身高而變動，以其為原點將使每位打者之座標系各不相同，無法跨打者比較；本壘板尖端為競賽規則所定義之固定實體位置，恆不變動，且與 MLB Statcast 座標系一致，具國際可比性。打者個人好球帶資訊並未因此喪失——PitchTracking 設有 sz_top_m／sz_bot_m 記錄該打者之好球帶上下緣，需要「相對好球帶位置」時得由此換算，反之則不可逆。
來源座標之處理：各資料來源若採其他原點（如以好球帶前緣中心為零點）或其他單位（如英吋、公分），一律由 ETL 於 Raw→Staging 階段換算至本標準之座標系與單位，換算規則載明於「來源資料對照表」，不另於本標準併列來源座標。生物力學骨架資料因各動作捕捉系統之座標慣例不一，須於 BiomechanicsFrame.forward_axis 與 up_axis 逐筆宣告其座標軸方向；軌跡多項式係數另須於 coeff_frame 宣告所依據之座標系與時間原點。（v0.5.0 依野球革命建議新增，原標準未統一宣告座標系）
時間與時區 所有日期與時間欄位以 ISO 8601 格式表示。timestamp 型別欄位須帶時區位移，本標準預設為 +08:00（國家標準時間）；date 型別欄位以中華民國國家標準時間之曆日為準
與上傳格式之
分層關係		 本標準規範資料本身之語意與結構（實體、欄位、值域），與運科中心《數據交換標準規範書－通用格式》所定之上傳封包格式分屬兩層，不相牴觸：
（一）封包層（通用格式）：JSON 頂層之 metadata／data 結構，含 organization_id、sport_codes、purpose、is_consent、data_id 等欄位，屬傳輸與授權管理之範疇，由上傳端依該規範填列。
（二）語意層（本標準）：封包內 data 陣列各筆資料之欄位語意、型別、值域與實體關聯，由本標準規範。
兩層之對應：封包層 organization_id 對應本標準 Organization、site_name 對應 DataProvider.site_name、sport_codes 對應代碼表 CL-000、is_consent 之批次授權狀態對應 Game.consent_batch_ref。各資料來源之原始欄位名稱與值域不一（同一概念於不同來源可能名為 RelSpeed、VeloRel 或其他），一律由 ETL 依「來源資料對照表」清洗對齊至本標準，本標準不因單一來源之命名而調整
個資保護 遵循個人資料保護法及數位發展部資料治理指引；所有含個資之資料須先經運科中心既有知情同意授權平台完成授權驗證，方得進入本標準資料流程（同意蒐集流程本身不在本標準規範範圍內）。因應運科中心既有系統需求，Player 已納入 email／phone（棒球另含 national_id）等高敏感欄位，均標記 PII 並要求加密或雜湊存放

本文件為國家運動科學中心（TISS）委託制定之羽球資料標準草案，採 Standards-as-Code 架構，以 YAML 為唯一真相來源，本 HTML 文件及 OpenAPI 規格均由 CI/CD 自動生成。賽事結構層與棒球共用 IPTC Sport Schema，傳統統計層依 BWF 官方規則，感測器量測層因無官方公開規格，改以國內學術資料集為參照依據，並於各欄位誠實標註來源等級。本標準所定義之欄位為完整概念範圍，實際資料是否收錄，依各資料來源單位可提供之項目與後續介接進度逐步納入，詳見下方「欄位收錄原則」。
§1 · 適用範圍（Scope）
維度 說明
欄位收錄原則 本標準列出之欄位為完整概念範圍，供未來擴充依循；實際是否收錄特定欄位之數據，依該資料是否可自資料來源單位取得而定，並非本案承諾一次到位蒐集所有欄位
參與者層級 國家代表隊等級（ELITE）、業餘（AMT）、U18／U15／U12、一般社會大眾（PUBLIC）
資料情境 正式比賽（Match）、有組織訓練、一般民眾自主運動（Session）
地理範圍 中華民國（臺灣）主辦，或我國球員／民眾參與之賽事或活動
感測層欄位 學術標註欄位（球種、落點、位置），依可取得之資料集逐步納入；技術可測惟規格未公開之預留欄位（球速）；欄位均為選填，無設備或規格未公開時以 null 填入
單位政策 量測欄位一律採公制，並依 ISO/IEC 11179 於欄位名稱後綴標註單位（如 release_speed_kmh、lead_distance_m）。例外情形以下列兩類為限，且均於該欄位附註載明理由：
（一）名稱本身為既定測試協定或器材規格慣例者，如 sprint_60yd_sec（球探標準測試名稱）、string_tension_lbs（羽球穿線磅數之國際通行慣例）——此類名稱中之英制字樣為測試協定名稱之一部分，非量測單位。
v0.5.0 撤銷之例外：原 plate_loc_x_m／plate_loc_z_m／sz_top／sz_bot 保留英尺以對齊 Statcast 好球帶分區定義一項，因野球革命建議書採全公制座標系（本壘板尖端為原點、單位公尺），為兩方架構一致並貫徹「量測欄位一律公制」原則，本版改採公制並撤銷該例外，欄位更名為 plate_loc_x_m／plate_loc_z_m／sz_top_m／sz_bot_m。
來源設備之原生單位與換算係數一律記載於該欄位附註，供 ETL 對照使用。

單位縮寫對照（本標準所用之後綴縮寫，一律採公制語意）：kmh＝公里／小時（km/h，非節）、mps＝公尺／秒（m/s，非英里／秒 miles per second）、cm＝公分、m＝公尺、rpm＝每分鐘轉數（revolutions per minute）、deg＝角度（°）、sec＝秒、min＝分鐘、pct＝百分比（%）、c＝攝氏度（℃）。例外後綴（政策例外，非公制）：ft＝英尺（僅好球帶座標系統）、lbs＝磅（僅羽球穿線磅數）、yd＝碼（僅 sprint_60yd_sec 測試名稱）
時間與時區 所有日期與時間欄位以 ISO 8601 格式表示。timestamp 型別欄位須帶時區位移，本標準預設為 +08:00（國家標準時間）；date 型別欄位以中華民國國家標準時間之曆日為準
個資保護 遵循個人資料保護法及數位發展部資料治理指引；所有含個資之資料須先經運科中心既有知情同意授權平台完成授權驗證，方得進入本標準資料流程（同意蒐集流程本身不在本標準規範範圍內）。因應運科中心既有系統需求，Player 已納入 email／phone（棒球另含 national_id）等高敏感欄位，均標記 PII 並要求加密或雜湊存放
